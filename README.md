# Frontend - Sandbox React & Next.js

Projeto de estudo prático focado nos fundamentos do React e na arquitetura do Next.js 14 (App Router), desenvolvido como parte da task de nivelamento.

## 🛠 Tecnologias

- [Next.js 14](https://nextjs.org/) (App Router)
- [React](https://react.dev/)
- [TypeScript](https://www.typescriptlang.org/)
- [Tailwind CSS v4](https://tailwindcss.com/)

## 📦 Como Rodar o Projeto
### Pré-requisitos
- Node.js instalado (Versão 18+ recomendada).

### Passo a passo

1. **Clone o repositório:**
```bash
git clone https://github.com/WellingtonLSoares/task-nivelamento-darm-labs-frontend.git
cd task-nivelamento-darm-labs-frontend
```

2. **Instale as dependências:**
```bash
npm install
```

3. **Inicie o servidor de desenvolvimento:**
```bash
npm run dev
```

4. **Acesse: Abra http://localhost:3000 no seu navegador.**
